# 🎮 PlayStation 5 Landing Page Clone

A high-fidelity, fully responsive clone of the official **PlayStation 5 landing page** — replicating the design, animations, and interactive experience of Sony's PS5 website using HTML, CSS, JavaScript, and ReactJS.

---

## 🌟 Overview

This project is a near-complete replica of the official PS5 landing page, built as a frontend showcase. It mirrors the visual design, layout, animations, and media content of Sony's original page — including video trailers, carousels, and immersive cover animations — with full mobile responsiveness.


---

## ✨ Key Features

- 🖥️ Full-page replica of the official PlayStation 5 website
- 🎬 Video trailers that open in **modal windows** for seamless in-page playback
- 🎠 **Interactive carousels** for product and game showcases
- 🎞️ Smooth **cover animations** for an immersive scroll experience
- 📱 Fully **mobile responsive** — works on all screen sizes
- ⚛️ **Component-based architecture** using ReactJS for clean, reusable UI
- 🔗 Images sourced directly from the official PS5 page

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 |
| Interactivity | JavaScript (ES6+) |
| UI Framework | ReactJS |
| Media | Official PS5 image CDN links |

## 🚀 Getting Started

### Prerequisites
- Node.js installed on your machine
- npm or yarn

### Run Locally
```bash
# Clone the repository
git clone https://github.com/dpatel3004/PS5-Clone.git

# Navigate into the project folder
cd ps5-landing-page

# Install dependencies
npm install

# Start the development server
npm start
```

The app will open at `http://localhost:3000`
